# unai

AI特有の不自然な言葉遣いだけを直す。

- 「実装の側で直す」→「実装を直す」、「その筋で進める」→「その方針で進める」、「層の地図」→「誰が何を見つけたか」。曖昧な「側」「筋」「層」「〜寄り」や自作の分類語は、具体的な言葉にする。
- 「ジョブが落ちる」→「ジョブが失敗する」、「余裕が食い潰される」→「余裕が足りなくなる」、「限界を突き破る」→「限界を超える」。位置や動きに寄せた歪んだ言い換えを直す。
- 「短く切るほうへ倒れる」→「短く区切りがちだ」、「その指示が効く」→「その指示で不必要に文を切らなくなる」。傾向や変化を曖昧に表す「倒れる」「効く」は、何をしがちなのか、何が変わったのかを書く。
- 「指示ではなく会話する」→「会話する」。意味のない否定を持ち出す「XではなくY」「その用途ではない」「〜わけではない」「ただ宣伝じゃない」は外し、伝えたい事実を書く。
- 「ブラックボックス」「ヘッドレス」「primitive」「ワンショット」「nonce」などの説明のない横文字は、日本語にするか意味を添える。ツール名の羅列は、何をするのかを書く。
- 「正直に言うと、対応できない」→「対応できない」。「正直に書いておく」「実は」「白状すると」「起きたことをそのまま書く」など、本題の前に付けるだけの断りを外す。
- 「地味に便利」→「便利」。強調として付ける「地味に」を外す。
- 「地味なルール」→「ルール」。書き手の意図にない卑下や評価を加える「地味な」「ただの」「〜しただけ」を外す。
- 「修正は1行。」→「直すのは1行で済んだ。」。不必要な体言止め、余韻を作るだけの短文の連続、ダッシュ（——）の溜め、「〜にしか見えない」「そもそも無かった」式の無理な強調を直す。
- 「鏡」「蘇る」「入口と出口」「重心が寄る」「燃える」「居座る」「効いてくる」「食い込む」など、説明を飾るだけの言い換えは、「増える」「関わる」「補う」「問題が出る」など、実際の意味を書く。
- 意図して設計した成果に付けた「狙っていなかった変化」「副産物として」「たまたま」は、設計と結果の関係が伝わる言葉に直す。

通常の意味で使う語や、区別に必要な否定は直さない。変更は該当する言葉遣いに限る。
