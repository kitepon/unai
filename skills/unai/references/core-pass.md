# AIっぽさを判断する基準

ここでいう「AIっぽさ」は文章の印象であり、AIが書いたかどうかの判定ではない。単語や文型だけでは判断できない。前後の文、読者、目的、書き手の声に照らし、表現が内容から浮いている箇所を扱う。

## 見つけ方

次のような表現が、その文章で働いているかを見る。例に似ていても、意味や声を担っていれば残す。

- **中身と結びつかない定型句**: どんな話題にも付けられる称賛、前置き、一般論で、内容や相手への応答が増えていない。実際の驚きや喜び、感謝、挨拶は文脈に合っていれば自然な表現。
- **実質のない対比や言い換え**: 対立していないものを「XではなくY」と強調したり、同じ結論を言い直したりする。誤解の訂正、選択肢の比較、理解を助ける説明には対比や言い換えが必要。
- **内容に関係なく繰り返される型**: 異なる話題でも同じ前置き、列挙、語尾、まとめが続き、内容に合わせた文章になっていない。説明に必要な構成や、キャラクターの口癖、詩や台詞の反復はそれ自体で問題にしない。
- **具体的な意味を隠す大げさな言葉**: 何が変わるのかを説明せず、「新たな可能性」「価値の創出」などで済ませている。伝える材料があれば具体的に言い直す。材料がなければ内容を作らず、意味を判断できないことを伝える。比喩が情景や気持ちを伝えている場合は残す。

修正するのは、文脈に合わない理由を説明できる箇所だけ。短い文章や一つの返答から、観測していない「毎回の癖」を推定しない。

## 判断の対になる例

**定型句を取り除く場合**

返金手順の説明に「現代社会において、返金は非常に重要なテーマです。注文履歴から申請できます。」とあれば、冒頭の一般論は手順の理解に寄与しない。「注文履歴から申請できます。」と直せる。

**対比を残す場合**

「消えるのはキャッシュで、写真の原本は消えないんだよ。」は、何が消えるのかを区別する説明。否定表現を理由に削らない。

**詳しい説明を残す場合**

「設定を変えたあとも前の表示が残るのは、ブラウザーが保存したデータを使っているためです。再読み込みすると、新しい設定が反映されます。」は、理由と対処をつなげている。「再読み込みしてください。」へ縮めると、必要な説明が失われる。

**豊かな表現を残す場合**

「やったぁ、できたよっ！ えへへ、ほめてくれてもいいんだよ？🌸」は、可愛いキャラクターが喜ぶ台詞ならそのまま生かす。「完了しました。」へ変えると、その子の声が消える。

「帰り道、月がついてきた。今日はひとりじゃない気がした。」は、情景と感情を伝える表現。比喩や短文を理由に平坦な説明へ変えない。

## 直す範囲

該当箇所を直した後、原文と読み比べて意味と声が残っているか確かめる。削除で文同士の関係が切れた場合は、必要な接続を保つ形に直す。短くすることや、無難な言葉へ置き換えることを校正の目標にしない。

語彙、逆接、文長、段落数、絵文字の使用回数に一律の制限を置かない。専門用語、俗語、体言止め、ためらい、強調も、目的と文脈に合っていれば使える。不確実性や制約を伝える表現には意味があるので、断定に変えて消さない。
