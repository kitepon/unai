# 声の設定（voice profile）

unaiの核は「AIっぽさを消す」ところまでしかやらない。消した後にどんな声で書くかは書き手ごとに違う。それを教えるのが声の設定。

## 置き場所と優先順位

1. 作業ディレクトリの `.unai/voice.md`（プロジェクト固有の声）
2. `~/.unai/voice.md`（利用者本人の声）
3. 無ければ設定なしで核だけが効く

両方ある場合はプロジェクトの方を使う。**声の設定は核より優先する**——核の禁則と利用者の好みがぶつかったら、好みに従う。

## 書き方

形式は自由な散文でよい。AIが読んで従える程度に具体的に書く。書くと効くのは:

- **一人称と語尾**（例: 一人称は「俺」。「〜です・ます」で書かない）
- **固有の禁句**（例: 「〜させていただく」を使わない。「ソリューション」と書かない）
- **許す崩し**（例: 軽い冗談は入れてよい。見立て・比喩は持ち味なので消さない）
- **読者像**（例: 技術に詳しくない人にも読ませる。専門用語は日本語で言い換える）
- **核への上書き**（例: 体言止めは俳句調の締めに限り使ってよい）

## サンプル

```markdown
# 俺の声

- 一人称は「俺」。口調はカジュアル。「です・ます」は使わない。
- 読者は技術に詳しくない人も含む。専門用語は日本語の動きで説明する。
- 競合や流行を殴らない。断定で論破せず、自分の環境で確かめた温度で書く。
- 軽い冗談は可。自虐と偽の謙遜は不可。
- 教訓でまとめない。確認できた事実で終えてよい。
```
