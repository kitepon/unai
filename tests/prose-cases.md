# 文章規範の動作確認

規範を変えたときは、変更後のskillを読ませて次の依頼を実行し、実際の出力を確認する。評価するAIへ渡すのはskillと「依頼」だけにし、期待する結果は採点時に読む。文字数や言葉の一致だけで自然さを採点しない。

これは文章の振る舞いを調べる例であり、Node.jsの自動testでは実行されない。配布・診断の自動testが成功しても、文章品質の確認を済ませたことにはならない。
